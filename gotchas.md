# Gotchas

- 2026-07-16: Do not infer that a user cannot manually view a macOS Data Protection Keychain secret merely because an ordinary application lacks the item's access-group entitlement. Apple TN3137 says Keychain Access supports the Data Protection Keychain and displays its password items. Distinguish programmatic application access from privileged human-facing access before making ownership claims.
- 2026-07-16: When Doctor Biz corrects the named research target, restate and verify the corrected target before proceeding. Here, “Muesli API” was corrected to Granola’s private API; Muesli is only the prospective client.
