With the default-off `companion_cli` feature enabled and Granola running, the app writes mode-0600 metadata to `appData/Granola/companion-cli/companion-cli.json` containing protocol version 1, a random per-run token, and the local socket path; the Unix socket is also mode 0600. The current muesli code does not use the bridge. The practical recovery path is to invoke the bundled CLI rather than reimplement its private socket protocol. Preconditions are Granola running, signed in, and the account/Labs flag enabled.
