Your meetings,

Muesli syncs your Granola meeting transcripts to local markdown and gives you fast full-text and semantic search. Everything stays on your machine.

Get started Download binary 
# Install from GitHub
$ cargo install --git https://github.com/harperreed/muesli.git --all-features

# Sync — picks up your Granola token automatically on macOS
$ muesli sync

# Search
$ muesli search "quarterly planning"

What it does

Simple ingredients,
well combined

Sync, search, summarize, and explore your meeting transcripts with a single binary. No accounts, no cloud, no telemetry.

Sync transcripts

Download and convert Granola transcripts to clean markdown with YAML frontmatter. Incremental updates only fetch what changed.

Full-text search

BM25-ranked keyword search powered by Tantivy. Find exact phrases across hundreds of meetings in under 50ms.

Semantic search

Meaning-based search using e5-small-v2 embeddings. Finds related concepts even without keyword matches. Runs entirely on your CPU.

AI summaries

Generate structured summaries with key topics, action items, and decisions using OpenAI. API key stored securely in macOS Keychain.

Terminal dashboard

Interactive TUI with markdown rendering, meeting stats, and attendee queries. Browse your meetings without leaving the terminal.

MCP server

Run as a Model Context Protocol server so AI assistants like Claude can search and reference your meetings directly.

Getting started

Three steps to breakfast

Set a token, sync, search. That's the whole thing.

  1. 01

    Authenticate

    If Granola is installed on macOS, muesli finds your token automatically. No setup needed. For other environments, set a bearer token manually.

    # Only needed if Granola isn't installed locally
$ export BEARER_TOKEN="your-token"
  2. 02

    Sync

    Download all your transcripts as clean markdown with frontmatter. Only changed documents are fetched on subsequent runs.

    $ muesli sync
  3. 03

    Search and explore

    Search by keyword or by meaning. Query by attendee or label. Launch the TUI for a full dashboard. Your data, your way.

    $ muesli search --semantic "improving team collaboration"

Two ways to find

Search that understands you

Keyword search for precision, semantic search for discovery. Both run locally with zero network calls.

BM25

Full-text search

Exact keyword matching ranked by relevance. Powered by Tantivy, the Rust equivalent of Elasticsearch.

$ muesli search "Q1 planning"
1. Q1 Planning Review (2025-01-15)
2. Team Planning Kickoff (2025-01-08)
3. Planning Retrospective (2025-03-20)
e5-small-v2

Semantic search

Meaning-based matching using 384-dimensional embeddings. Finds related concepts without exact keyword overlap.

$ muesli search --semantic "how do we
  handle customer feedback"
1. Support Triage Process (2025-02-12)
2. NPS Review Meeting (2025-01-30)
3. Voice of Customer Sync (2025-02-05)
